    建置與 GitHub 發布

    1. 儲存內容

    將後台資料寫入 data/site.json，並自動建立備份。

    2. 建置檢查

    執行 node scripts/build-pages.mjs，確認 GitHub Pages 靜態包可產生。

    3. Commit

    將目前變更加入 Git 並建立 commit。

    4. Push

    推送到 origin main，由 GitHub Actions 部署 Pages。

    Security

    本地防護策略

    本機限定

    伺服器預設只綁定 127.0.0.1，外部網路無法直接連入。

    Microsoft 防護

    建議維持 Windows Security、Microsoft Defender Antivirus、Windows Defender Firewall 開啟。

    靜態部署

    GitHub Pages 只部署 dist/ 靜態前台，不部署 Python API、後台與維護工具。

    密碼設定

    正式使用請先設定 NCUT_ADMIN_PASSWORD，不要使用預設密碼長期維護。
